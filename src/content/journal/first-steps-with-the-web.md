我开始做这个博客时，最先注意到的是页面长什么样。后来才发现，一个网站不只是屏幕上的设计，它也是浏览器读取并呈现的一组文件。

可以先用三个问题来理解常见的前端基础：

1. **HTML**：页面里有哪些内容，它们之间是什么关系？
2. **CSS**：这些内容应该如何排列、留白和呈现？
3. **JavaScript**：用户操作时，页面需要怎样回应？

这个博客会尽量把这些层次留得清楚一些。我可以从改一段文字开始，再尝试改样式，最后给按钮加上交互。每一次改动，都能在浏览器里直接看到结果。

## 一个小实验

试着在归档页点选“学习”或“生活”，看看文章列表怎样变化。这个小功能由浏览器里的 JavaScript 完成；文章本身则在网站构建时从 Markdown 转成页面。
